# NEET UG 2027 — AI Hinglish Explanation System

## 1. Objective

Provide NEET aspirants with an intuitive, conversational breakdown of verbatim NCERT statements in natural Hinglish (conversational Hindi mixed with authentic English scientific terminology), alongside standard English and pure Hindi translations.

## 2. Core Pillars of Each Explanation

1. **NEET High-Yield Focus**:
   Identifies the weightage, frequency, and core concepts tested by NTA in recent NEET examinations.
2. **Concept Simplification**:
   Translates dense NCERT prose into structured, easy-to-understand conversational bullet points.
3. **Trap Alerts**:
   Highlights common student misconceptions (e.g., confusing Archaebacteria cell walls with peptidoglycan).
4. **Mnemonics & Memory Aids**:
   Provides memorable acronyms and formulas to lock in facts.

## 3. Data Storage

In `Topic` model:
- `hinglishExplanation`: Full conversational Hinglish text.
- `englishExplanation`: Standard academic English breakdown.
- `hindiExplanation`: Hindi academic breakdown.
- Toggled seamlessly on the client via the language selector pills.
